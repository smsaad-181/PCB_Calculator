# IPC-2221 legacy trace current (S-001, S-010)

Retrieved 2026-10-06. IPC-2221 was not read (paywalled).

## Agreed by all secondary sources
I = k · ΔT^0.44 · A^0.725, with I in A, ΔT in °C rise, A in mil², k = 0.048 (external), k = 0.024 (internal).
- CircuitCalculator.com (2006): "based on a curve fit to IPC-2221 (formerly IPC-D-275)"; width = area / (oz × 1.378 mil/oz).
- SMPS.us: curves "reproduced in Figure 6-4 of IPC-2221B"; same k and exponents; output has no derating.
- Advanced Circuits (advancedpcb.com): word-for-word the same as CircuitCalculator, so not independent.
- twc and KiCad legacy use the same constants (cross-check only).

Status PAYWALLED-USER-MUST-VERIFY. The secondary sources call the equation a curve fit *to the chart*. We could not tell whether IPC-2221 prints the equation or only the chart.

## Validity range (S-010)
- CircuitCalculator / Advanced Circuits: chart covers "up to 35 Amps, up to 0.4 inches of trace width, from 10 to 100 degrees C", 0.5 to 3 oz/ft².
- KiCad legacy help text (seen via search result only): 35 A external / 17.5 A internal, ΔT ≤ 100 °C, width ≤ 400 mil.
- Conflict (minor): a separate internal current limit, and whether there is a lower ΔT bound of 10 °C. Not averaged.
- Unverified search snippet: the original chart includes a nominal 10 % current derating.

## Edition
The current edition is IPC-2221C, released 2023-12-01 and replacing IPC-2221B (DIN Media; technickenormy.cz). Whether Revision C keeps Figure 6-4 or defers to IPC-2152 is unknown.

## KiCad note (for crosscheck-tools.md X-01)
The KiCad development branch (doxygen, master) has replaced the IPC-2221 track-width formula with the Brooks & Adam IPC-2152 fit. KiCad 9.0 stable docs still say "formulas from IPC-2221". Any KiCad cross-check record must name the KiCad version.

## IPC-2221C public information (2026-10-07)
- **Official revision highlights** (technickenormy.cz; DIN Media, 2023-12-01, 176 pp.):
  - Topics listed: material and copper foil selection, palletization, edge plating, "minimum electrical clearance (e.g., dielectric withstanding voltage, corona effect and creepage)", impedance tolerances, plane clearances, feature location tolerances, press-fit pins, back-drilling.
  - Current-carrying capacity and IPC-2152 are **not mentioned**.
- **NextPCB blog** (updated 2026-05): claims 2221C "retains the empirical Annex B and Annex C charts" and defers more explicitly to IPC-2152.
  - The same blog swaps the k values, so it is unreliable and not used.
- **KiCad master** (`panel_electrical_spacing_ipc2221.cpp`, tier 4) cites "IPC2221C Dec 2023" with 8 categories:
  - B1 internal.
  - B2 external uncoated, ≤ 3050 m.
  - B3 external uncoated, > 3050 m or vacuum.
  - B4 permanent polymer coating.
  - B5 conformal coating.
  - A6 component lead with conformal coating.
  - A7 lead uncoated, ≤ 3050 m.
  - A8 lead uncoated, > 3050 m or vacuum.
  - KiCad 7.0/9.0 has 7 categories (B1–B4, A5–A7). The change appears to add a lead category for high altitude or vacuum and to renumber the conformal-coating category from A5 to B5. This is secondhand; the table values were not compared.
- **Trace-current chart:** no reliable public statement on whether the IPC-2221C chart or its axis ranges changed.

## User must verify
- IPC-2221C Table 6-1: the category list and values; whether a B5/A8 split exists.
- IPC-2221B §6.2 and Figure 6-4, and the same clause in IPC-2221C (2023): whether the equation is printed, k values, exponents, chart axis ranges (current, width, ΔT, copper weight), the derating note, and any statement deferring to IPC-2152.
